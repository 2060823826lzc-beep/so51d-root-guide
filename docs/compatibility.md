# 支持范围与验证边界

电脑端允许已连接、已授权的 Android 手机自主选择尝试。该入口不等于通用兼容承诺，原生程序仍有内核匹配检查。

| 完整内核 | 所选配置 | 已有证据 |
|---|---|---|
| `5.15.170-android13-8-00015-g52ccd9134339-ab12915929` | SO-51D CPU 3/4 | 历史 SO-51D 临时 Root 成功；同时出现框架重启及内核警告 |
| `5.15.189-android13-8-00016-g51bba4309aac-ab14546557` | Xperia 1 V CPU 0/1 | 上游配置参考与离线核验；不是本版完整实机验收 |
| 其他内核 | 默认实验配置 | 未宣称适配；可能因原生匹配检查而停止 |

Root 流程不刷写分区；完整重启后临时 Root 消失。缺少 KernelSU 管理器时可安装随包的指定版本；不自动覆盖、降级或清除已有不同版本的数据。

小白条操作不限制机型，但要求 Root、机主用户，以及可读取的 SystemUI 手势条颜色和覆盖接口；隐藏要求手势导航。恢复仅移除本工具创建的覆盖，不改变导航模式。

详细配置见 `profiles/catalog.json`。历史测试摘要经筛选后位于 `profiles/tested-records.json`，不包含原始个人诊断日志。
