## 实验性质与风险

本工具尝试获得临时 Root 并执行部分系统操作。允许尝试不表示已验证适配；历史成功不保证同款设备、不同固件或下一次执行成功。已知可能出现失败、卡死、框架异常、内核警告、重启、功能变化及数据损失。请先备份并自行判断是否适合使用。

当前结果只反映检测时的状态，不构成长期稳定性或安全性结论。完整重启后本方案取得的临时 Root 会消失，但已安装的应用、模块文件、授权记录和修改过的系统设置可能继续保留；重启不等于恢复出厂状态，也不会自动撤销所有操作。

Root 会扩大获授权程序可访问和修改系统、应用及数据的范围。仅向可信应用授予必要权限；第三方模块的行为、兼容性及风险需另行核实。本项目的测试结果不覆盖使用者自行安装的全部模块或后续修改。

## 操作、取消与恢复边界

使用前请核对型号、固件和完整内核，确认备份可用，并了解该设备的重启、恢复及数据恢复条件。型号相同、界面允许执行或离线测试通过，都不能代替当前设备的实机验证。不要同时运行其他 Root 或刷机工具。

“取消并恢复亮屏”在等待解锁阶段阻止启动 Root，并尝试恢复此前记录的充电常亮设置。激活已开始后，关闭窗口、断开 USB 或停止电脑端等待，不代表手机端程序已停止或操作已撤销。“取消常亮 / 恢复设置”只恢复记录的常亮设置；“恢复小白条”只处理相应资源覆盖，均不等于撤销 Root、卸载模块或恢复所有系统修改。

发生断线、异常或重启时，请先检查手机状态和日志，按使用说明处理待恢复设置；不要通过删除尝试标记来绕过同一次开机的重复尝试限制。恢复操作本身也可能因连接、权限或系统状态异常而失败，需核验结果。
