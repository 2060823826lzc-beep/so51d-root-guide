# 使用说明

## 准备

备份重要数据。仅连接需要操作的一台手机，开启 USB 调试，在手机上允许此电脑。解压完整便携包到可写目录，保留全部子目录，运行 `SO51D-Root-Tool.exe`。

操作前阅读 [使用与责任声明](disclaimer.md) 和 [支持范围](compatibility.md)，核对设备信息，并了解重启与恢复方法。不要同时运行其他 Root 或刷机工具。

## 操作

1. 点击“刷新检测”，查看型号、固件、完整内核、Root 状态和配置选择。
2. 需要尝试临时 Root 时，点击“执行一次 Root”。执行可能失败、卡死或重启。
3. Root 默认不修改充电常亮。需要时勾选“操作期间保持 USB 充电常亮”，该辅助失败不会阻止 Root。等待解锁时可继续或“取消本次操作”。
4. 执行后核验当前 Root 和服务状态、收集日志；若修改过临时常亮则恢复原值，不强制观察五分钟。
5. Root 可用时，按检测结果隐藏或恢复小白条。界面刷新可能要求重新解锁。

首页“充电常亮”显示手机当前设置和核验时间。“开启 USB 常亮”将手动设置改为 USB 供电常亮，“关闭充电常亮”关闭所有供电方式的常亮。首次手动修改前的原值会保留，多次开关也不会覆盖，可用“恢复原设置”撤销。

Root 临时辅助使用独立记录，仅增加 USB 常亮、保留其他供电方式，结束或取消后恢复 Root 前的设置，不覆盖手动恢复记录。若 USB 常亮原本已开启，则无需修改。断线或恢复失败保留记录，连接原手机后点击“恢复临时设置”。新版恢复记录绑定对应手机，旧版未绑定的记录会明确提示。

空闲时每 15 秒自动核验，操作后立即回读；自动刷新不会生成一批新的运行日志。断线或读不到实际设置时显示“状态未知”。`null` 显示“系统默认（未显式设置）”，不当作常亮已关闭；手动修改后可恢复成未设置状态。

常亮开关不会主动点亮屏幕、解锁或修改屏幕亮度。恢复原值也不等于关闭常亮，例如原来为 USB 常亮，恢复后连接 USB 仍常亮。

临时常亮不是 Root 的执行条件。原值无法读取、为 `null` 或格式异常、开启失败时，提示手动保持亮屏并继续 Root。存在旧待恢复记录或记录无法读取时保留原记录，跳过本次辅助，仍可继续 Root。

取消等待解锁可以阻止启动 Root；激活开始后，关闭窗口或停止电脑端等待不代表手机端程序已经停止。恢复常亮、小白条或完整重启均不等于撤销全部系统修改，安装的应用、模块文件和设置可能保留。

## 结果与日志

当前 Root 成功与长期稳定是不同结论。新记录的五分钟观察显示“未进行”。完整日志位于 `logs/`，本机历史位于 `history/`，同一次开机的尝试标记位于 `attempts/`。

同一次开机不重复尝试，不自动重试。已有 Root 时跳过激活；模块已加载但 Shell 无权限时，应先检查 KernelSU 授权。连接中断、卡死或重启后，请先检查结果和日志。

日志可能含设备标识和应用路径。反馈问题前按 [隐私说明](../PRIVACY.md) 脱敏。
